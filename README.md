# 佐野家のごはん — recipe-book

家庭のレシピ、ネットで見つけた料理、自分なりのアレンジを一か所に集める、スマートフォン向けのレシピ管理PWAです。「佐野家の定番」を見つけやすくし、献立ルーレットで毎日の料理選びを助けます。

**現在は設計段階です。アプリ本体・PWA・公開用CIは未実装で、利用できる本番サイトはまだありません。** 本リポジトリは今後のCodex Cloud開発の基準となる設計書を管理しています。

## 目的と採用技術

個人開発として開発・運用コストを最小限に抑え、初期版はAndroid Chromeのスマートフォン1台で使います。

- React + TypeScript + Vite
- GitHub Pagesで静的公開、PWAで保存済みレシピをオフライン利用
- IndexedDBでレシピ・写真・履歴を端末内保存
- サーバー、ユーザー登録、ログイン、クラウドDB、有料APIは不要

補助ライブラリの採用初期案は[ARCHITECTURE](docs/ARCHITECTURE.md)を参照してください。現時点で依存関係の導入は行っていません。

## 初期版で予定する機能

- 写真・材料・分量・手順・メモ・URLを持つレシピの登録、編集、削除
- 料理名や材料の検索、カテゴリ・タグの絞り込み、お気に入り「佐野家の定番」
- 料理写真やスクリーンショットの添付と端末内での圧縮
- カテゴリ・お気に入り・タグ・最近の調理を条件にした献立ルーレット
- 献立の決定履歴と実際に作った調理履歴
- 外部ブラウザでのWeb検索と、URL・必要情報の手動登録
- 写真を含むファイルへのバックアップと復元

OCR、AI画像解析、外部サイトからの自動取り込み、買い物リスト、家族間同期は将来の検討対象です。

## データについて

データは利用端末のブラウザ内に保存する設計です。ブラウザデータの削除、端末故障、保存領域の自動解放等で失われる可能性があり、永続性は保証できません。**バックアップは初期版の必須機能**とし、ファイルを端末外にも保管する運用を推奨します。アプリの静的ファイルをGitHub Pagesに公開しても、家庭のレシピデータはGitHubへ送信しません。

## 今後の開発

1. Phase 1：基本レシピブック、写真、IndexedDB、バックアップ・復元。
2. Phase 2：献立ルーレット、決定履歴、調理履歴。
3. Phase 3：Web検索導線、URL保存・手動登録フローの完成。
4. Phase 4：UI改善、PWA、Android実機検証、GitHub Pages本番公開。
5. Future：規約と技術の条件を満たす自動取り込み、買い物リスト、家族共有。

初期版の一般利用開始はPhase 4の完了後です。Phase 1からバックアップを使え、Phase 2より前からデータ互換性を管理する計画です。

次回のCodex Cloudでは、[AGENTS.md](AGENTS.md)を読んでから、[ROADMAP](docs/ROADMAP.md)のPhase 1を指定して開発を開始できます。実装・テスト・公開手順のコマンドは、実装時に追加します。
